**[En cámara]**

En esta clase vamos a ver todas las herramientas que vamos a utilizar para crear nuestro
propio videojuego.

Lo primero es descargar el repositorio del curso.

**[Mostrar: clonar el repositorio con git clone y abrir la carpeta. Viene la base del
proyecto y el Estudio de assets, sin ningún juego: el juego lo construimos nosotros]**

Después, Claude Code, o Claude Desktop.

**[Mostrar: la página oficial de Claude Code, cómo se instala y cómo se abre en la carpeta
del proyecto]**

Vamos a utilizar el editor de videojuegos Godot Engine.

**[Mostrar: godotengine.org, descargar la versión 4.7.2 para Windows. Viene en una carpeta
con dos ejecutables, uno con ventana y otro de consola; no se instala]**

Vamos a utilizar la API de OpenAI para generar las imágenes.

**[Mostrar: platform.openai.com, cargar créditos en Billing y crear una key en API keys]**

Y ElevenLabs para la generación de audio.

**[Mostrar: elevenlabs.io, elegir un plan y crear una key]**

**[Mostrar: el archivo .env.local en la raíz del proyecto, con OPENAI_API_KEY y
ELEVENLABS_API_KEY. Tapa las keys en pantalla: quien las vea puede gastar tus créditos]**

Y por último, el Estudio de assets, que viene en el repositorio: un visor y editor donde
vemos, escuchamos, creamos y regeneramos todas las imágenes y los audios del juego.

**[Mostrar: python tools/studio/server.py, que abre http://localhost:8765. Pasar por las
pestañas Imágenes y Audio y abrir el botón Crear nuevo]**
