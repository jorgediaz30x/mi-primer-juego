# Curso: crear un videojuego con Claude Code

- [prompts.md](prompts.md): los 8 prompts, uno por clase, para copiar en Claude Code.
- [guiones/](guiones/): lo que se dice en cámara en cada clase.
- [clases.md](clases.md): el comando para dejar el proyecto como queda al terminar cada clase.

## Orden de las clases

| # | Clase | De qué trata |
|---|---|---|
| 1 | Presentación | Quién eres, qué se va a construir y se muestra el juego terminado |
| 2 | Herramientas | Claude Code, Godot, GPT Image, ElevenLabs y el Estudio de assets |
| 3 | Cómo está construido un juego | Teoría con Vallebruma de ejemplo: sprites, audio, movimiento, configuración |
| 4 | El arte | Personajes, escenarios, efectos e interfaz con GPT Image, revisados en el Estudio de assets |
| 5 | El prompt del juego | Se le pide a la IA el juego completo y lo arma usando el arte ya generado |
| 6 | La animación | Las animaciones de los personajes y el jefe |
| 7 | La música y el sonido | Música y efectos con ElevenLabs |
| 8 | Mejoras y publicación en la web | Balance, pantalla de inicio y menús, y exportar el juego a la web |
